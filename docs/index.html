§02 · Specifications and standards

Specifications and standards

  • KerML 1.0 (OMG) - Formal specification of the Kernel Modeling Language that underpins SysML v2.
  • SysML 2.0 (OMG) - Formal OMG specification of the SysML 2.0 language and its transformation, including machine-readable libraries.
  • SysML v2 tools page (OMG) - OMG directory of tools that have announced SysML v2 support.
  • sysml-v2-docs - Community-oriented mirror and notes on the SysML 2.0 specification documents.
  • SysML.org - SysML Partners site with a SysML v2 hub covering FAQs, tools, and training.
  • Systems Modeling API 1.0 (OMG) - Formal specification of the Systems Modeling API and Services with REST and OpenAPI platform-specific models.
§03 · Official implementations

Official implementations

  • SysML-v2-API-Cookbook - Recipes for working with the Systems Modeling API.
  • SysML-v2-API-Java-Client - Java client library for the Systems Modeling API.
  • SysML-v2-API-Services - Reference implementation of the Systems Modeling API services built on Spring.
  • SysML-v2-Pilot-Implementation - Reference implementation of the textual notation and visualization based on Xtext and Eclipse.
  • SysML-v2-Release - Official incremental release of the specifications, standard libraries, sample models, and installers.
§04 · Editors and language tooling

Editors and language tooling

  • daltskin/sysml-v2-grammar - ANTLR4 grammar for SysML v2 generated from the OMG BNF.
  • daltskin/sysml-v2-lsp - ANTLR4-based language server and MCP server for SysML v2.
  • daltskin/VSCode_SysML_Extension - VS Code extension for editing SysML v2.
  • DeciSym/sysml-mode - Emacs major mode for editing SysML v2.
  • mycr0ft/pygments-sysml - Pygments lexer for syntax highlighting SysML.
  • mycr0ft/sysml-vim - Vim syntax support for SysML.
  • nomograph-ai/tree-sitter-sysml - Tree-sitter grammar for SysML v2.
  • sensmetry/sysml-2ls - Open language support library for SysML v2 used by the Syside editor.
  • Syside Editor (VS Code) - Free VS Code and Open VSX editor extension for SysML v2 from Sensmetry.

§06 · Parsers, SDKs, and API clients

Parsers, SDKs, and API clients

  • ansys/pysam-sysml2 - Python API client and object model for SysML v2 aligned with Ansys SAM.
  • demaconsulting/SysML2Tools - Toolchain for .NET that parses, lints, and renders diagrams for SysML v2.
  • mycr0ft/sysmlpy - Python parser for SysML v2 built on ANTLR.
  • Open-MBEE/sysmlv2-python-client - Community Python client for the SysML v2 API.
  • Open-MBEE/sysmod-sysmlv2-api - SYSMOD extension for the SysML v2 API with MCP support.
  • sireum/hamr-sysml-parser - SysML v2 parser derived from the pilot ANTLR grammar for the HAMR toolchain.
  • STARIONGROUP/SysML2.NET - Implementation of OMG SysML 2 for .NET with an associated web viewer.
  • Westfall-io/sysml2py - Python parser for the SysML 2.0 textual notation.
  • zbigniewsobiecki/sysml2 - Command-line tool that parses, validates, queries, and modifies SysML v2 models.

Validation and analysis
